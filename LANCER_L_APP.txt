TESTER LE FILTRE DE TABLEAU
============================

Sur la page "Vols / Cambriolages":

1. Scroller jusqu'au tableau en bas

2. Voir le champ: "🔍 Filtrer le tableau: [_______] [🔄 Réinit]"

3. Taper quelque chose: "projecteur"
   → Tableau doit afficher seulement les vols de projecteur
   → Voir le compteur: "X résultats trouvés (sur Y total)"

4. Taper quelque chose d'autre: "nord"
   → Tableau doit afficher seulement les incidents du Nord
   → Compteur doit se mettre à jour

5. Cliquer "🔄 Réinit"
   → Tableau doit redevenir complet
   → Compteur doit redevenir "Y incidents"

DÉPANNAGE RAPIDE
================

Problème: L'app ne démarre pas
Solution:
  1. Vérifier que clean_and_restart.bat existe
  2. Vérifier que Python est installé (python --version)
  3. Relancer: clean_and_restart.bat

Problème: "TOP STATISTIQUES" ne s'affiche pas
Solution:
  1. Rafraîchir la page (F5)
  2. Relancer l'app: clean_and_restart.bat

Problème: Graphiques cassés
Solution:
  1. Rafraîchir la page (F5)
  2. Vérifier les logs (console)
  3. Relancer l'app

Problème: Filtre de tableau ne fonctionne pas
Solution:
  1. Rafraîchir la page (F5)
  2. Vérifier qu'il y a des données
  3. Relancer l'app
