EXEMPLE D'UTILISATION
====================

SCÉNARIO 1: Vue d'Ensemble Complète
  1. Sélectionner "Vue Générale"
  2. Garder "Tous" pour le département
  3. Voir tous les incidents, toutes catégories, tous départements

SCÉNARIO 2: Analyser Vols du Nord
  1. Sélectionner "Vols / Cambriolages"
  2. Sélectionner "Nord" dans la sidebar
  3. Voir seulement les vols du Nord
  4. Optionnel: utiliser le filtre page pour un sous-département

SCÉNARIO 3: Tendances Blessures
  1. Sélectionner "Blessures Corporelles"
  2. Garder "Tous"
  3. Voir timeline, distribution, statistiques des blessures

DÉTAILS TECHNIQUES
==================

Catégorisation:
  • Fonction: categorize_incident(row)
  • Analyse: Chaque colonne du fichier
  • Détection: Mots-clés prédéfinis
  • Colonne créée: 'Catégorie'

Navigation:
  • Type: Radio buttons (un seul choix)
  • Options: Vue Générale + catégories
  • Mise à jour: Dynamique en temps réel

Filtres:
  • Département (Sidebar): Affecte toutes les pages
  • Département (Page): Affecte seulement la page actuelle
  • Type: Dropdowns

Graphiques:
  • PIE: Distribution catégories (Vue Générale)
  • BAR: Distribution départements
  • LINE: Distribution temporelle
