  Local (PowerShell) → GitHub → Streamlit Cloud (navigateur)

PROCESSUS RAPIDE (RÉSUMÉ POUR DÉJÀ CONNAISSANTS GIT)

1. git init && git add -A && git commit -m "Initial"
2. Créer repo GitHub
3. git remote add origin ... && git push -u origin main
4. Aller sur https://share.streamlit.io/ → New app
5. Lier GitHub repo (VOTRE_USERNAME/sfa-works-incidents, branch main, app.py)
6. Une fois déployé → Settings → Secrets → ajouter GOOGLE_CREDENTIALS
7. ✅ App live !
