ÉTAPE 7: CONFIGURER LES SECRETS (Streamlit Cloud)
──────────────────────────────────────────────────────────────────────────────

⚠️  CRITIQUE: credentials.json doit être ajouté en tant que Secret, pas en fichier

7.1. Sur votre app Streamlit Cloud, en haut à droite, cliquez votre avatar (☰)
7.2. Cliquez "Settings"
7.3. À gauche, cliquez "Secrets"
7.4. Copiez le CONTENU COMPLET de votre fichier credentials.json local
7.5. Collez-le dans le champ Secrets avec la clé "GOOGLE_CREDENTIALS":

     [general]
     GOOGLE_CREDENTIALS = """
     {
       "type": "service_account",
       "project_id": "unique-hour-385920",
       "private_key_id": "17858f691bf91d997fca0a6bd625b13691fa1f68",
       ...
       (TOUT le contenu JSON)
     }
     """

7.6. Cliquez "Save"
7.7. L'app redémarre automatiquement avec les secrets
7.8. ✅ Vérifier: Barre latérale affiche "🟢 Connecté à Google Sheets"

DÉPANNAGE RAPIDE

Erreur "Module not found":
  → requirements.txt manque gspread/google-auth
     Vérifier: pip list | findstr gspread

Erreur "PERMISSION_DENIED":
  → Sheet pas partagé avec service account
     Vérifier: Partager → to-05-649@...

Erreur "No module named 'streamlit'":
  → Impossible sur Streamlit Cloud (devrait fonctionner)
     Vérifier les logs: Settings → Logs

Problème après git push:
  → Attendre 2-3 minutes (redéploiement automatique)
  → Rafraîchir la page (Ctrl+F5)
  → Vérifier les logs
